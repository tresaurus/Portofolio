# Dwi Cahyaning Putri — Portfolio Website

Responsive personal portfolio featuring data analysis, statistics, machine learning, research, and digital content creation.

## Preview locally
Open `index.html` in a web browser.

## Before publishing
- Replace `your.email@example.com` in `index.html` with your professional email.
- Replace the general LinkedIn and GitHub URLs with your own profile links.
- Add links to real notebooks, repositories, dashboards, or published digital assets when available.
- Review project descriptions to ensure they accurately reflect completed work and current experience.

## Publish with GitHub Pages
1. Upload `index.html` to the root of the repository.
2. Open repository Settings → Pages.
3. Under Build and deployment, select Deploy from a branch.
4. Select your main branch and `/ (root)`, then save.

The website uses Google Fonts when online and falls back to system fonts if they cannot load.
