# Dwi Cahyaning Putri — Portfolio Website

A responsive, single-page portfolio website built with HTML and CSS.

## Preview locally
1. Extract `dwi_portfolio_website.zip`.
2. Open `index.html` in a web browser.

## Personalize before publishing
Open `index.html` and update:
- `your.email@example.com` with your real email address.
- LinkedIn and GitHub URLs with your profile links.
- Project descriptions and add links to completed projects.
- Skills and biography as needed.

## Publish for free
You can publish this static website using GitHub Pages:
1. Create a GitHub repository.
2. Upload `index.html` to the repository root.
3. Open repository Settings → Pages.
4. Select deployment from the main branch and save.
5. GitHub will provide your public website URL.

The site uses Google Fonts when online; system fonts will be used if they cannot load.
